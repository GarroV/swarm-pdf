# swarm-pdf — PDF-редактор SWARM

Форк [BentoPDF](https://github.com/alam00000/bentopdf) (AGPL-3.0) для раздела «Полезности» SWARM
(решение владельца 03.10.2026, задача GarroV/Swarm-brain#771). Изменения форка — только в
ветках `swarm/*` и в этой папке; в исходный репозиторий ничего не отправляется.

## Что чиним

1. Буквы, которой нет во встроенном шрифте документа, нет и после правки — рисуется рамка «нет буквы».
2. Удлинённый абзац наезжает на следующий — нижележащий текст не сдвигается.

## Проверка

`swarm/check/pdfcheck.py <файл.pdf>` — код возврата 1, если в файле есть буква без рисунка
(рамка вместо глифа, в том числе нарисованная синтезом шрифта) или наложение строк. Нужны
`pip install fonttools pikepdf` и poppler (`pdftotext`). Проверено на файле владельца:
исходник — чисто, файл после правки BentoPDF — обе поломки найдены.

Тестовые PDF владельца в репозиторий не кладутся (персональные данные) — только синтетические.

## Что сделано (03.10.2026)

| Поломка                     | Причина                                                                                 | Починка                                                                                                                                        | Где                                                                                                                                                  |
| --------------------------- | --------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| Рамка вместо буквы          | ядро переиспользует встроенное подмножество и для букв, которых в нём нет               | кусок с непокрытыми буквами → метрически совместимый Liberation (Sans/Serif/Mono), только если проверка cmap подтверждает исходные буквы куска | `src/js/editcore/swarm-font-substitute.js`, вызов в `core.js` (`previewParagraph`/`commitParagraph`); тест `src/tests/swarm-font-substitute.test.ts` |
| Абзац наезжает на следующий | сдвиг нижележащих (`cascadeParagraphGrowth`) был только у правки кликом и смены формата | общий `commitWithCascade` и в «Заменить», «Заменить всё», исправлении опечатки                                                                 | `src/js/editcore/app.js`                                                                                                                             |

Шрифты Liberation 2.1.5 (OFL) — `public/fonts/liberation/`, грузятся фоном при открытии редактора.

## Сквозная проверка

```
BASE=https://<адрес> node swarm/check/replace-run.cjs <chrome> <папка с in.pdf> "<найти>" "<заменить>"
python swarm/check/pdfcheck.py "<папка>/out/in (edited).pdf"
```

Проверено на файле владельца на превью `swarm-text-edit-fixes.swarm-pdf.pages.dev`: до починки — рамка в
заголовке и наложение абзацев, после — чисто (pdfcheck и картинка страницы).

## Выкладка

Cloudflare Pages, проект `swarm-pdf`. Сборка одной командой — `swarm/build.sh`, выкладка —
`npx wrangler pages deploy ../dist-deploy --project-name swarm-pdf --branch main` (другая
`--branch` даёт превью `<ветка>.swarm-pdf.pages.dev`, прод не трогает).

`swarm/build.sh`:

- скачивает из npm движки инструментов — cpdf (склейка, часть разрезания), Ghostscript и PyMuPDF
  (сжатие, картинки → PDF, PDF → Word) — тех версий, что записаны в
  `src/js/utils/wasm-provider.ts`, в `public/wasm/` (в git не лежат, ~80 МБ);
- собирает с `SIMPLE_MODE=true` и `VITE_WASM_*_URL=/wasm/...`: без этого BentoPDF грузит движки с
  `cdn.jsdelivr.net`, то есть чужой код получает доступ к файлу в браузере. Проверено записью
  запросов 03.10.2026: склейка на прежней сборке тянула `cdn.jsdelivr.net`, на новой — только наш адрес;
- откатывает файлы, которые сборка правит сама (блог, `security-headers-docs.conf`, `src/partials`);
- готовит `../dist-deploy` без `libreoffice-wasm` (файлы > 25 МБ — лимит Pages; конвертация Office
  не работает). Файлы движков больше 25 МБ скрипт ловит до сборки.

## Подборка шрифтов (03.10.2026)

Список «Шрифт» показывает только то, что встроится: Arial/Times/Courier (под ними метрически
совместимые Liberation), PT Sans/Serif, Roboto, Open Sans, Montserrat, Noto Sans/Serif
(`public/fonts/`, OFL, статические начертания, подмножество латиница/кириллица/греческий) и системные,
если их открыли («System fonts», ниже подборки). Названий без файла в списке нет — на кириллице они
давали рамки вместо букв.

- Каталог и загрузка — `src/js/editcore/swarm-font-catalog.js` (шрифт грузится в момент выбора).
- `detachRestyledRuns` (`swarm-font-substitute.js`): кусок со сменённым семейством отвязывается от
  исходного, иначе ядро молча оставляло встроенный шрифт документа.
- Проверка: `node swarm/check/font-run.cjs <chrome> <dir> "PT Serif" 1` (BASE — адрес редактора),
  затем `pdffonts` (должен быть `PTSerif`) и `pdfcheck.py`. Загрузка файла в headless идёт 15–40 с.

## Режим встраивания (03.10.2026)

Swarm открывает инструменты панелью «PDF» с iframe на `/<инструмент>?embed=1` (править текст, склейка, разрезание, сжатие, страницы, поворот, подпись, картинки → PDF, PDF → PNG, PDF → Word — у каждой страницы первой строкой `import './swarm-embed'`). С этим параметром
`src/js/logic/swarm-embed.ts` прячет обвязку сайта BentoPDF: верхнее меню, «Back to Tools»,
хлебные крошки, подвал и заголовок. Без параметра страница не меняется. Заголовков,
запрещающих встраивание (X-Frame-Options, frame-ancestors), у Pages-проекта нет; разрешение на
стороне Swarm — `frame-src` в его `miniapp/scripts/gen-csp-headers.mjs`.

## Перевёрстка при «Заменить всё» (03.10.2026)

Выросший абзац склеивался ядром со следующим, нижние абзацы наезжали. Место освобождается до
сохранения (рост из предпросмотра), модель страницы перечитывается — только в «Заменить всё»
(`commitWithCascade(..., makeRoom=true)`); ручная правка идёт прежним путём.

## Запасные шрифты до открытия файла (swarm-pdf#2)

Правка до прихода запасных Liberation записывала в абзац букву без рисунка («с□едения»).
Файл открывается после их загрузки (`metricFontsReady` в `edit-pdf-text-page.ts`, пока ждём —
индикатор загрузки), но не дольше 20 с: зависшая сеть не должна запирать редактор. Проверка —
`swarm/check/race-run.cjs`: задерживает шрифты в браузере (`FONT_DELAY`) и правит сразу.

## Список элементов и новое поле (swarm-pdf#3)

- Кнопка-список в панели справа открывает слева «Elements»: текстовые блоки и картинки страницы
  сверху вниз. Щелчок — выделить, прокрутить к элементу, открыть правку; корзина — удалить тем же
  путём, что Delete (`#del`). Пересобирается из `updateChrome`. Типы объектов движка — числа:
  1 текст, 2 фигура, 3 картинка.
- Режим «T» уступает щелчок только существующему текстовому полю. Раньше уступал и картинкам — на
  скане (вся страница одна картинка) протяжка с «T» тащила сам скан вместо нового поля.
- Новое поле набирается тем же шрифтом и размером, что сохранится: первые буквы браузер вставляет
  рядом с пустым span-затравкой, и они наследовали 13px поля — после сохранения текст «сжимался».
- Проверка — `swarm/check/elements-run.cjs <chrome> <pdf>` (BASE, EXT): поле → щелчок мимо →
  выбор щелчком и из списка → удаление из списка.

## Проверка порядка слов

`swarm/check/pdfcheck.py out.pdf --orig in.pdf --replace было=стало` сверяет слова страницы с
исходником после той же замены: разорванный или переставленный абзац даёт расхождение, даже если
строки не пересеклись.
